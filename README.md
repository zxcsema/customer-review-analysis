# Анализ отзывов клиентов T-Bank

Учебный анализ клиентских отзывов: доля негатива по продуктам и темам, сравнение
групп клиентов и проверка связи факторов с тональностью. Данные лежат в
`data/customer_reviews.xlsx`, разбор выполнен в `customer_review_analysis.ipynb`.

Для таблиц использованы pandas и NumPy, для статистической проверки — SciPy,
для графиков — Matplotlib и Seaborn.
